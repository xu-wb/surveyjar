# 安装与快速开始

目标是启动工具，填写一份演示问卷，再查看保存的答卷。示例只用于熟悉操作。

## 1. 准备环境

需要 **Python 3.10 或更新版本**和一个现代浏览器。问卷工具没有第三方 Python 依赖，无须运行 `pip install` 或 npm 命令。

在终端检查：

```sh
python --version
```

已有项目文件夹时直接使用即可，也可以从公开仓库克隆：

```sh
git clone https://github.com/zh1peng/surveyjar.git
cd surveyjar
```

## 2. 启动工作台

Windows 双击项目根目录的 **启动SurveyJar.cmd**，或在终端运行：

```sh
python server.py
```

浏览器自动打开 `http://127.0.0.1:8765`。如果没有自动打开，手动输入这个地址。

首次启动会创建空数据库。保持服务窗口运行，使用结束后关闭窗口即可停止服务。

## 3. 创建演示问卷

1. 进入「我的问卷」，点击「载入示例问卷」。已有问卷时可点击「新建问卷」。
2. 查看问卷名称、题目、选项和必填设置。
3. 点击「预览作答」，试选几项并检查布局。预览不保存答卷。
4. 返回编辑，点击「保存问卷」。

::: tip 正式保存与编辑器草稿
编辑中的内容会保存在当前浏览器，但只有点击「保存问卷」后，问卷才会进入数据库。
:::

## 4. 填写并提交

在问卷卡片上点击「开始填写」，完成必填题后点击「提交答卷」。填写过程中约 600 毫秒自动保存一次草稿；界面会显示保存状态。

提交成功页不显示总分和维度分。研究人员可以返回工作台，进入「收集结果」查看答卷详情。

## 5. 查看与导出

在「收集结果」勾选这份问卷，点击「预览宽表」，确认列与分数后点击「导出合并宽表 CSV」。

如果需要把同一参与者的多份问卷合并到一行，请先创建[项目与批量填写](./projects)，而不是分别填写后只使用相同编号。
