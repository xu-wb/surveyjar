# 工具概述

SurveyJar 把创建问卷、现场填写和整理数据放在同一个本地工作台里。它适合研究人员在一台电脑上准备问卷，并安排参与者轮流填写。

## 能做什么

| 环节 | 功能 |
| --- | --- |
| 准备问卷 | 新建题目，导入 TXT、JSON、DOCX，核对识别结果 |
| 调整结构 | 选择题型、必填规则、选项和分组，预览实际作答 |
| 配置计分 | 原始分、反向转换、数字映射、维度求和或平均 |
| 收集回答 | 单份填写、项目批量填写、保存并继续草稿 |
| 整理结果 | 查看答卷，筛选问卷与项目，导出合并宽表 CSV |

## 三个基本概念

**问卷**包含题目、选项和计分设置。修改后点击「保存问卷」，才会正式保存到数据库。

**项目**把多份问卷排成一个填写顺序。例如「基本信息 → 日常状态 → 选择任务」。

**作答批次**是某位参与者完成一个项目的一次过程。同一参与者再次完成项目会产生新批次；导出时不同批次分别占一行。

## 数据留在哪里

正式问卷、作答草稿、提交答卷、项目和批次保存在 `data/questionnaires.sqlite3`。尚未正式保存的编辑器草稿保存在当前浏览器。

程序源码可以通过 Git 同步；研究数据库与个人材料保留在本机。详细区别见[保存、备份与迁移](./data)。

## 使用边界

- 服务只监听本机 `127.0.0.1`，没有远程收集入口。
- 参与者专注界面隐藏工作台导航，但这不是研究人员权限控制。
- 程序执行你配置的计分规则，不自动识别专业量表算法。
- 导入后核对题目、选项、必填和反向设置，再正式收集。
