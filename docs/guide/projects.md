# 项目与批量填写

一个项目定义需要填写哪些问卷，以及填写顺序。一次作答批次把同一参与者在这个项目中的多份答卷关联起来。

## 创建项目

进入「项目与批量填写」，点击「创建项目」，按图配置。

填写第一份问卷并提交后，点击「继续下一份问卷」。全部完成后，界面提示保存完成，可以返回工作台。

正式作答界面及提交位置见[填写并提交](./getting-started#_4-填写并提交)。

批次在开始时保存问卷和计分规则，避免中途编辑项目影响同一轮填写。

## 中断与继续

关闭页面后，可从「被试作答批次」点击「继续本批次」。程序会恢复未完成问卷的草稿。

同一被试、同一项目存在未完成批次时，再次开始会继续该批次。已完成后再次开始会创建新批次，适合重复测量。

## 被试编号与专注界面

被试编号只在开始时录入一次，后续自动沿用。问卷中名称为「编号」「被试编号」「受试者编号」「参与者编号」的文本题会自动填入该编号并隐藏。

正式作答时隐藏侧边导航和工作台顶部，提交与问卷切换期间保持专注界面。此设计用于减少干扰，不提供身份或权限隔离。

## 导出时怎样合并

| 情况 | 宽表中的结果 |
| --- | --- |
| 同一批次的多份问卷 | 合并为一行 |
| 同一被试的不同批次 | 分别占一行 |
| 单独填写的问卷，即使编号相同 | 不自动合并 |
| 同一问卷的不同题目或计分版本 | 使用独立列组 |

具体筛选和列含义见[结果与宽表导出](./results)。
