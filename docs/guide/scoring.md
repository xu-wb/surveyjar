# 计分与维度

编辑器中的「计分与维度」配置问卷级规则；每道题的计分方式、原始分值和反向设置配置题目级规则。

## 原始分与反向计分

先填写各选项的**原始分值**，再单独勾选反向。例如 0、1、2、3 的选项不需要手工倒序改成 3、2、1、0。

```text
反向后分数 = 最大分值 + 最小分值 − 原始分值
```

| 原始分（0～3） | 反向后分数 |
| --- | --- |
| 0 | 3 |
| 1 | 2 |
| 2 | 1 |
| 3 | 0 |

多选题逐个选项反向后求和。数字题和量表题使用配置的 `min + max − 填写值`。

## 数字映射

数字题使用「自定义分值／数字映射」时，每行写一个映射：

```text
0=0
1=1
2=3
3=5
```

未匹配值计 0 分。若勾选反向，使用映射分值（含默认 0）的最小值与最大值进行转换。

## 配置维度

1. 点击「添加维度」，填写唯一的维度名称。
2. 选择求和或平均分。
3. 在维度卡片的「包含的题目」中勾选计分题。

也可以在题目的「所属维度」中分配。两处同步；每道题只能属于一个维度，分配到新维度会从原维度移出。

## 总分规则

| 规则 | 含义 |
| --- | --- |
| 所有计分题求和 | 直接累加题目计分后的分数 |
| 所有计分题平均分 | 对题目计分后的分数求平均 |
| 不计算总分 | 只保留题目分与已配置的维度分 |

总分直接按题目汇总，不会再次把维度分相加。未分配维度的计分题仍可参与总分。

::: info 缺失值不是 0
任何计分题缺失，包括选填题，相关维度和总分会留空。没有计分题的汇总也留空。程序不会自动插补缺失值。
:::

## 仅收集原始数据

需要在外部使用专门算法时，选择「仅收集原始数据」。该模式保留回答和配置的原始分值，不产生计分后分数、维度分或总分。MCQ 模板默认使用这一模式。

## 作答后的规则调整

导出默认使用作答时保存的问卷规则。如果之后才设置反向或维度，可以选择「当前反向与维度规则」：

- 只调整本次报告使用的方向、维度和汇总规则。
- 原始选项分值仍采用作答快照。
- 不覆盖数据库中的历史答卷。

新旧题目按内部 ID 对应。已删除的旧题保留原规则，新题不会产生虚构的历史回答。
