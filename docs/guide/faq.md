# 常见问题

## 双击后没有打开工作台

先确认 `python --version` 为 3.10 或更新版本，再在项目根目录运行 `python server.py` 查看错误信息。如果服务已经启动，可以手动访问 `http://127.0.0.1:8765`。

同一端口已运行一个实例时，无须再次启动。关闭多余窗口后再操作。

## 浏览器提示无法连接本地服务

检查服务窗口是否仍在运行。不要通过双击 `web/index.html` 使用工具；界面需要由 Python 服务提供数据库与导入接口。

## 为什么同一被试的多份问卷没有合并

相同编号不足以建立关联。需要在「项目与批量填写」中完成同一批次，导出才会合并到一行。单独填写的答卷分别保留。

## Word 导入的题型不对

查看导入预览中的表格读取方式，尝试选择共用选项量表、逐题独立选项或迫选题表格。重新解析会替换尚未保存的预览修改，应先确定读取方式，再调整题型。

## JSON 提示题目 ID 不合法

每个题目 ID 必须唯一，只使用字母、数字、下划线和连字符，例如 `q1`、`mood_02`。引号、空格、HTML 和其他特殊字符不允许作为题目 ID。

## 为什么总分或维度分是空白

先检查是否选择了「仅收集原始数据」或「不计算总分」。再查看相关计分题是否有缺失，包括选填题。没有计分题的汇总也留空。

## 修改反向后，已有答卷为何没有变化

已有答卷保留作答时的规则。需要调整本次报告时，在「收集结果」选择「当前反向与维度规则」。它不会覆盖原始记录。

## 清除浏览器数据会丢失所有答卷吗

已写入 SQLite 的答卷仍保留。清除浏览器会影响尚未正式保存的编辑器草稿及未写入完成的恢复副本，因此清理前先完成保存与数据库备份。

## 能把链接发给参与者远程填写吗

当前版本不支持。`127.0.0.1` 指向访问者自己的电脑，适合同一台电脑轮流填写。文档站也只是使用说明，不能代替问卷工作台。
