在问卷卡片上点击「编辑」。修改问卷名称、说明和题目后，点击「保存问卷」正式保存。

已有答卷和作答草稿保留各自的问卷快照。修改正式问卷不会自动重写这些记录。计分说明见[计分与维度](./scoring)。

## 支持的题型

| 题型 | 填写方式 | 说明 |
| --- | --- | --- |
| 单选 | 选择一个选项 | 按选项原始分值计分 |
| 多选 | 选择多个选项 | 计分时逐项转换后累加 |
| 迫选 | 从多个选项中选择指定数量 | 始终必填；选择数量必须小于选项总数 |
| 量表 | 从整数刻度中选择 | 最多 21 个刻度 |
| 数字 | 输入范围内的数值 | 可配置数字到分值的映射 |
| 文本 | 自由输入 | 不计分 |
| 物质使用 | 是否使用过，若是则填写年数 | 年数可为小数；不计分 |

题目支持上下移动、复制和删除。除迫选题外，可以自行设置是否必填。

## 迫选题

迫选题没有默认选择。可添加多个选项，并设置必须选择几项。例如四个选项中选两项；不能要求选择全部选项。

不计分的迫选题在宽表中记录所选项的序号；配置分值后按选中项求和。程序不自动推断专门的迫选量表算法。

## 将条目归为共同题目

例如「烟草」与「酒精」可以放在共同标题「物质使用」下显示：

1. 用上下箭头把需要分组的条目排在一起。
2. 勾选连续条目，填写共同题目标题。
3. 点击「将勾选条目归为一题」。

分组只改变显示结构。子条目的答案、题目 ID 和计分仍独立保留。点击「取消勾选条目的分组」可恢复独立显示。
