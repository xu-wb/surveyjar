# 更新记录

## 0.1.0

首个版本提供本地问卷准备、填写与数据整理流程。

- 创建与导入问卷，支持 TXT、JSON 和普通 DOCX 表格。
- 提供单选、多选、迫选、量表、数字、文本与物质使用题。
- 配置原始分、反向转换、数字映射、维度与总分。
- 管理项目、批量填写、作答草稿与问卷快照。
- 筛选结果并导出合并宽表 CSV。
- 校验问卷、答案题型和答卷状态，检查本机写请求来源。
- 校验题目 ID，并转义作答界面的 HTML 属性。

本版本文档使用 VitePress，配有 SurveyJar SVG 标志、中文导航、本地搜索与深浅色主题。

[查看 v0.1.0 程序标签](https://github.com/zh1peng/surveyjar/tree/v0.1.0)
