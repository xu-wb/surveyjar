# SurveyJar · 本地问卷工具

需要 Python 3.10 或更新版本，无须安装任何第三方库。

双击 `启动SurveyJar.cmd`，或在项目文件夹执行 `python server.py`。浏览器自动打开 http://127.0.0.1:8765 。保持命令窗口运行；结束时关闭窗口。

## 使用流程

1. 新建问卷，或载入示例。支持单选、多选、量表、数字、文本。
2. 编辑题目、选项和必填设置；使用上下箭头排序，可复制和删除题目。
3. 选择正向、反向、自定义或不计分。点击「保存问卷」正式保存。
4. 点击「开始填写」。草稿自动写入本机，必填题未完成时定位并提示。
5. 提交后在「收集结果」查看每题回答与分数，导出 JSON 或 CSV。草稿可继续填写。

「导入与说明」提供可下载的 UTF-8 TXT、JSON 模板。支持粘贴 Word 表格（带表头）、横排题目与选项、共用选项；也可以直接选择 DOCX 文件，按【问卷名称】分开预览后保存。不支持 PDF。旧版逐行 TXT 仍兼容。明确分值按原文保留，不推断反向题或专业量表算法。未标分题目不计分，导入默认必填，可在编辑器修改。

横排示例：`1.你的状态如何？ | 没有=0 | 偶尔=1 | 经常=2`。
共用选项：先写 `选项：没有=0 | 偶尔=1 | 经常=2`，然后每行一道题。
可用 `[多选]`、`[文本]`、`[选填]`、`[反向]` 标记；横排导入保留原始分值和独立反向标记；按最小值 + 最大值 − 分值换算，未标分时原始分为 1…N。

DOCX 普通多列表格按表头选项与每行分值读取；双列表单按文本或明确列出的选项读取。不能识别的正文、题意与选项不一致的内容会在预览中提示，保存前请核对。

## 计分与维度

编辑问卷顶部的「计分与维度」可添加维度名称，并选择求和或平均分；可在维度卡片的「包含的题目」列表直接勾选计分题，也可在每道题的「所属维度」中分配，两处同步。每道题属于一个维度，勾选到新维度会从原维度移出。未分配维度的计分题仍参与总分。

- 选项分值为原始分值，可用 0～3、1～5 或自定义值。反向单独勾选，按最小值 + 最大值 − 原始分计算，多选逐项换算后求和。
- 数字／量表正向为填写值，反向为 min + max − 填写值。数字映射使用映射分，未匹配为 0；反向映射按映射分（含默认 0）的最小值 + 最大值 − 映射分。
- 总分支持全部计分题求和、平均，或不计算总分（只算维度）；不会对维度重复相加。
- 任何计分题缺失（包括选填）时，相关维度和总分留空，不当成 0 分，也不擅自插补。没有计分题的汇总留空。
- 特殊算法请选「仅收集原始数据」。该模式保留回答和已配置的原始分值，不产生计分后分数、维度得分或总分。MCQ 模板默认此模式。
- 维度题号和反向题需按所用版本的正式规则自行配置，程序不自动推断。
- 物质使用题按类别提问，选择使用过后填写时长（年，可用小数）；选否隐藏并清除时长。该题型不计分。

「收集结果」先勾选问卷、选择项目和是否包含草稿，再预览或导出合并宽表 CSV。每行是一名被试的一次项目作答，每列一道题；题目ID、题型、回答文字等不作为数据列。原始分保持原样，仅反向题增加相邻的「反向计分」数值列。每份问卷题目后依次追加维度分及问卷总分，维度列名附题号。不同量表不直接相加成跨量表总分。

非计分文本和非计分普通选择题不进入分数表；原始回答仍在数据库保留。物质使用以0/1与使用年数导出；MCQ 没有量表原始分，按1/2保存所选奖励（非得分），对应选项文字写在列名。缺失、不适用、未计算留空，0分保留为0。筛选范围没有答卷时会提示，不再下载空文件。单独的维度导出入口已取消。

默认按作答时的问卷规则计算导出。若之后才设置反向或维度，可选择「当前反向与维度规则」：只调整本次报告的方向、维度和汇总规则，原始选项分值仍采用作答快照，不覆盖历史数据。题号对应基于内部题目ID；已删除的旧题保留原规则，新加的题目不虚构旧回答。

旧答卷不重算。旧记录的原始分可由当时的问卷快照还原，但当时若已将反向分直接写进自定义选项，无法自动恢复未保存的原始分规则。修改计分只影响之后的新答卷；原有填写草稿仍使用原来的问卷快照。

## 数据

数据库：`data/questionnaires.sqlite3`。关闭服务后复制该文件即可完整备份；恢复时关闭服务再替换。删除问卷保留已有答卷。删除答卷无法撤销。

编辑器草稿保存在当前浏览器 localStorage；正式问卷、填写草稿、提交答卷都保存在 SQLite。填写后约 600 毫秒自动保存，界面显示状态；未写入的内容有浏览器恢复副本。不要同时在多个标签编辑同一份草稿。

仅监听本机回环地址，不访问网络，不含 CDN、遥测或外部字体。适合同一台电脑轮流收集，没有远程收集、用户权限或数据加密。请使用电脑账户和文件权限管理数据访问。

技术栈：原生 HTML/CSS/JavaScript + Python 标准库 HTTP 服务 + SQLite，无构建过程、包管理器、哈希或 SHA 基础设施。

## 导入操作位置

导入在浏览器中的问卷工作台操作：

1. 双击「启动SurveyJar.cmd」，保持弹出的命令窗口运行。
2. 若浏览器未自动打开，手动访问 http://127.0.0.1:8765 。
3. 点击「我的问卷」右上角「导入问卷」，再点击「选择文件」。
4. 选择自己的 DOCX 或 TXT 问卷文件；通用模板位于项目的 `examples/` 目录。
5. 页面显示识别预览；勾选需要的问卷，点击「保存勾选问卷」。
6. 回到「我的问卷」，点击「编辑」调整计分，或点击「开始填写」。

直接运行 import_questionnaire.py 现在也会启动工作台。它不会自动把项目中的文档写入问卷库。

## 迫选题

选择「迫选题（二选一）」，固定两个选项、始终必填且不默认选择。选项文字可修改，不能添加第三项。合并宽表用 1／2 表示第一／第二项（非得分），对应文字写在列名中。MCQ 仍采用仅原始数据模式。横排格式：`[迫选]请选择 | 现在获得 | 以后获得`。历史答卷和已有草稿保留原题型，新填写使用新设置。

## Word 表格读取方式

导入预览逐表显示识别类型和题数。连续题号＋两个完整文字选项识别为迫选题；共用选项表头＋题干与分值识别为量表。合并标题不作选项。可逐表切换「自动识别／迫选题表格／共用选项量表」，切换会重新解析原文件，重置尚未保存的预览编辑。读取错误解决前不能保存，避免遗漏题目。TXT 或粘贴单张表格可在识别前选择方式。

迫选表格按行保留两项文字、原文题号，不给金额或天数计分；明确符合奖励文字格式时，额外保留即时金额、延迟金额、天数和币种，完整问卷快照仍保留这些属性；精简宽表不额外展开这些属性列。重新导入只生成待保存的新问卷，不覆盖历史问卷或答卷。


## 项目与批量填写

1. 进入「项目与批量填写」→「创建项目」，命名并勾选问卷，用上下箭头设置填写顺序。
2. 点击「批量填写」，录入被试编号（如 S001），开始一个作答批次。
3. 提交一份问卷后点击「继续项目／查看完成情况」，进入下一份；中断后可在批次列表继续，草稿自动恢复。
4. 同一被试同一项目有未完成批次时继续该批次；已完成后再次开始会创建新批次，不覆盖上一次测量。
5. 「收集结果」选择问卷与项目，点击「导出合并宽表 CSV」。同一批次的问卷合并在一行；同一被试不同批次分行，单独填写的答卷不凭编号自动拼接。

批次在开始时固定问卷与计分规则，避免中途编辑影响同一轮填写。没有被试编号的历史答卷显示「未填写编号」。不同版本问卷在合并时使用独立列组，避免把不同题目或分值混在同一列。

提交完成页仅显示保存成功和后续操作，不显示总分、维度分或结果入口；研究人员仍可在「收集结果」查看和导出。批量填写只在开始时录入一次被试编号，后续自动沿用；问卷中的文本题「编号／被试编号／受试者编号／参与者编号」自动填入该编号并隐藏。

正式作答自动进入专注界面，隐藏侧边导航、顶部工作台栏和问卷内的返回按钮。提交与批量问卷切换期间保持专注界面，全部完成后可返回工作台。中途需要停止时可关闭页面，已自动保存的草稿可在工作台继续。
## 导入结构与人工调整

导入前可选择自动识别、基础信息表（双列）、共用选项量表、逐题独立选项、迫选题表格或混合问卷。此设置适用于 DOCX 和横排 TXT。JSON 和旧版逐行模板沿用文件内的题型。

- 基础信息表使用两列，分别为项目名称和填写内容或选项。
- 共用选项量表第一行为选项表头，后续每行为题目及分值或空白作答格。
- 逐题独立选项每行写题目和它自己的选项。可用 `选项=分值` 指定分值。没有选项的行保留为文本题。
- 迫选题表格每行写连续题号及至少两个选项，默认选一项。导入后可在编辑器修改必须选择的数量。
- 混合问卷按每张表格自动判断。TXT 中不同表格之间留一空行，每张表保留自己的表头。`【问卷名称】` 用来分隔不同问卷。

DOCX 在预览中还可逐表切换读取方式。重新解析会替换整份导入预览，因此应先确定读取方式，再手动编辑。

点击“调整题型与分组”可以修改题型、选项、计分和必填设置。将有关条目排列在一起，勾选连续条目并填写共同题目标题，再点击“将勾选条目归为一题”。例如烟草和酒精可以归入“物质使用”，各自保留是否使用及使用时长。勾选条目后点击“取消勾选条目的分组”即可恢复为独立问题。分组只改变显示结构，各条目的答案和计分字段仍独立保留。

迫选题支持多个选项，并可设置必须选择几项。选择数量须小于选项总数。旧问卷没有设置选择数量时仍按二选一或多选一处理。多项迫选若配置分值，按选中项求和；不自动推断专门的迫选量表算法。

用“预览作答”检查实际布局和选择规则。试填不保存答卷。完成后返回编辑，再返回导入预览，最后点击“保存勾选问卷”。
