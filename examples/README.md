# 通用导入模板

本目录中的模板也可以直接作为演示问卷导入。

| 文件 | 用途 | 预期读取结果 |
|---|---|---|
| `问卷导入模板.txt` | 横排题目、共用选项、表格文本 | 3 份问卷，分别为 4、2、2 道题 |
| `问卷导入模板.json` | 单选、反向量表、数字映射、文本 | 1 份问卷，4 道题 |

启动程序后，在「我的问卷 → 导入问卷 → 选择文件」中选择上述文件，核对预览后再保存。保存会向当前本地问卷库新增演示问卷。

目前未提供通用 Word（DOCX）模板。程序支持导入 DOCX，不代表仓库已经附带 DOCX 示例。`local/materials/` 中的 Word 文件是个人研究材料，不是共享模板。

`tests/test_examples.py` 直接读取本目录的 TXT 和 JSON，检查题目结构及部分计分结果，不写入数据库。这些测试不代替浏览器界面操作验证。

网页中的「下载模板」目前由 `web/app.js` 内置示例生成，并非读取本目录；其 JSON 示例与本目录的自定义计分示例不同。
